# Plan

Build a Go + Fiber API with one endpoint returning a minified JSON object containing a name and dynamic timestamp, containerize it, automate build, verification, and image publishing through GitHub Actions, and deploy it to a cloud platform.

## Approach

Work in small, verifiable stages and push progress after each working stage.

1. Repo setup and plan
2. Local Go + Fiber API
3. Docker containerization
4. GitHub Actions CI for build, verification, and Docker Hub publishing
5. Cloud deployment
6. Automated deployment on main branch changes
7. Demo preparation

- Go + Fiber
- Docker
- GitHub Actions
